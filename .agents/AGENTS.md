# AegisLink — Project Rules

## Git Workflow
- **Never push directly to `main`**. Always create a feature/fix branch first.
- Branch naming: `feat/<name>`, `fix/<name>`, `chore/<name>`, `refactor/<name>`.
- After committing and pushing the branch, provide the user with the GitHub PR creation link.
- PR link format: `https://github.com/gabinotech22-cmyk/AegisLink/compare/main...<branch-name>`
